새 HTML 파일은 목록에 먼저 나타날 수 있어요. GitHub Pages 게시가 끝나기 전에는 링크가 열리지 않을 수 있습니다. 배포 완료 후 다시 방문해 주세요.

책장을 불러오는 중이에요.

공개 저장소에서 HTML 파일 목록을 확인합니다.

목록이나 링크가 보이지 않나요?

처음 사용한다면 HTML 상단의 CONFIG.owner와 CONFIG.repo를 채우세요. 공개 저장소의 main 브랜치와 root 폴더가 기본값입니다.

지정한 폴더 바로 안에 있는 .html 파일만 표시합니다. 하위 폴더와 index.html은 제외합니다. 카드 제목은 확장자를 뺀 파일명이며 책 본문은 읽지 않습니다.

인증 없는 API는 일반적으로 IP 주소별 시간당 60회 제한이 있습니다. 같은 학교 네트워크에서는 제한을 함께 사용할 수 있으니 반복 새로고침을 피하세요. 실패 시 저장된 이전 목록이 있으면 확인 시각과 함께 표시합니다.

파일 변경 후 다음 새로고침마다 API에 다시 요청합니다. 브라우저 HTTP 캐시를 재검증하지만 GitHub 측 캐시와 게시 지연 때문에 즉시 반영은 보장되지 않습니다. 배포는 보통 잠시 기다려야 하며 공식 안내상 최대 10분이 걸릴 수 있습니다.

한 폴더의 항목이 1,000개 이상이면 API 특성상 일부가 누락될 수 있습니다. 페이지에 경고를 표시하며, 이 경우 더 작은 폴더로 나누어 관리하세요.
